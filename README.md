# 📚 Tech Watch - Veille Technologique

Collection personnelle de ressources de veille technologique organisée par domaines d'intérêt.

## 📂 Contenu

### [Data Engineering](veille-data-engineering.md)
Ressources sur l'ingénierie des données : Modern Data Stack, orchestration, warehouses, streaming, qualité des données, et architectures.

### [DevOps & Cloud](veille-devops-cloud.md)
Outils et pratiques DevOps : Kubernetes, CI/CD, IaC, monitoring, sécurité, et cloud platforms (AWS, GCP, Azure).

### [Game Dev Lua & macOS](veille-gamedev-lua-macos.md)
Développement de jeux avec Lua (LÖVE2D, Defold) et développement sur Apple Silicon (M1/M2/M3/M4).

### [Linux Rice & Arch](veille-linux-rice-arch.md)
Personnalisation Linux, Arch Linux, window managers, ricing, dotfiles, et outils CLI.

### [Tech Générale](veille-technologique.md)
Vue d'ensemble des technologies : IA/ML/LLM, langages (Python, Rust, Go), actualités tech, et tendances émergentes.

## 🎯 Objectifs

- **Centraliser** les meilleures sources d'information par domaine
- **Organiser** une veille structurée et efficace
- **Partager** les ressources avec la communauté
- **Maintenir** un processus scalable dans le temps
